# PassMarkedu A-level 阅卷

把 A-level / IAL 真题答卷交给 AI，按 **考试局官方评分标准** 逐个得分点批改，拿回三份 PDF。

## 能做什么

- **按官方评分标准判分**：每个得分点（M1、A1、B1……）对照 Pearson Edexcel 与 Cambridge（CAIE）官方评分标准原文判断，总分和等级由 PassMarkedu 服务端统一计算，并按对应考季的官方分数线给出参考等级。
- **整卷、拼题卷、单张照片都能批**：整份真题从封面识别卷号和考季；几份真题拼成的练习卷、或随手拍的一道题，会先读出题干，在 PassMarkedu 题库里找到原题再批。
- **三份 PDF**
  - **批改答卷**：保留原卷，红笔标出每小问得分和得分码。
  - **阅卷结果**：得分总览、主要失分点、逐题错在哪、应该怎么写，并附官方评分标准原页。
  - **复核说明**：只列 AI 拿不准的几处，每处附答卷截图、该小问的官方评分标准和两种判法，由你来定。
- **改分一句话**：认为哪处该改，回复「第 N 处改成 X 分」，三份 PDF 会一起更新，不另扣次数。

## 支持范围

- **Edexcel IAL**：数学、进阶数学、物理、化学、经济、会计、生物
- **CAIE AS & A Level**：数学、进阶数学、物理、化学、经济、会计、计算机科学

具体年份见 [passmarkedu.com/marking-kit](https://passmarkedu.com/marking-kit#faq)。

## 怎么用

1. 安装后按提示连接 PassMarkedu A-level 账号：打开链接登录（没有账号用手机号注册），核对授权码，点「授权」。
2. 上传答卷 PDF 或按页顺序的照片，说「帮我批改这份试卷」。
3. 几分钟后拿到三份 PDF，链接保留 7 天。

免费账号可批 1 份整卷和 5 道单题（拍照或拼题卷按题计），订阅后不限次数。

## 说明

- AI 判分仅供参考，教师的判断是最终依据。复核说明里列出的地方请人工确认。
- 不同 AI 模型读手写和判断得分点的能力不同，结果可能有差别。
- 隐私：批改结果保存 7 天，答卷处理方式见 [隐私政策](https://passmarkedu.com/privacy)。
