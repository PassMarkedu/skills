# Levels: Edexcel IAL Chemistry (WCH11–WCH16) — 6-mark extended answers

The 6-mark items are indicative points (IP) plus reasoning marks, added — the same shape as physics, with one extra rule (MS WCH12/WCH15). Sources: Examiner Reports June 2025 WCH13–WCH16.

| IP seen | IP marks | reasoning marks usually |
|---|---|---|
| 6 | 4 | 2 |
| 5 | 3 | 2 |
| 4 | 3 | 1 |
| 3 | 2 | 1 |
| 2 | 2 | 0 |
| 1 | 1 | 0 |

Reasoning is still judged on the structure (2 coherent and sustained, 1 partial, 0 unlinked); the "usually" column is the MS's expectation, not an entitlement.

- "Look for the indicative marking points first, then consider the mark for the structure" (WCH12 MS p.22). Example: 5 IP, partially structured = 3 + 1 = 4 (WCH15 MS p.28).
- **Incorrect chemistry deducts from the reasoning marks** (not below 0): "If there is any incorrect chemistry, deduct mark(s) from the reasoning" (WCH15 MS p.28).
- An IP needs its full content: the fragment's formula **and** positive charge for an m/z peak (WCH14 p.34); the correct complex formula (WCH15 p.52). IPs count in any order, and an equation can stand for the words (WCH15 p.55). Unnecessary data (chemical shift values) is ignored, not penalised (WCH14 p.30).
- Stored as separate IP `point` steps plus reasoning, or as one `level` step: as for physics — judge each IP, then reasoning within the usual band, minus incorrect chemistry; note the IPs found.
