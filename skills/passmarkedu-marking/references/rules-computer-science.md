# Computer science

Use the official checklist and mark-scheme image for this question. The general marking rules still apply.

- **Code and pseudocode:** transcribe exactly, preserving indentation, case, operators, indexes, boundaries and the order of statements. Never repair a syntax or logic error while transcribing. Award a method or syntax point only on the conditions in its check; accept alternative languages, pseudocode conventions or equivalent algorithms only where the scheme permits them.
- **Trace tables and output:** record the actual entries, including blanks and their row/column positions. Check each required state change or output in order. Do not substitute the output the program ought to produce for the output written on the script.
- **Binary, hexadecimal and calculations:** preserve leading zeros, sign, bit width and units where relevant. Follow the scheme's acceptance rules for representation, overflow and rounding; a mathematically equivalent value need not satisfy a required bit pattern. Only use a numeric step when the supplied checklist labels it numeric.
- **Definitions and explanations:** judge the required meaning in the context of the question. Matching a keyword alone does not establish the required relationship or cause. Follow official allow/reject guidance and list limits.
- **Logic gates, networks and other diagrams:** describe connections, directions, labels and truth-table entries in pass 1; judge each visual point from the actual diagram, with low confidence where unreadable.

Do not invent extra requirements, such as insisting on an explanation of a correct algorithm when the official mark scheme does not require one.

## Examiner conventions (CAIE 9618 Examiner Reports 2024–2025; quotes in the bench's `records/examiner-reports/`)

- Marking points (MP): any valid solution is marked against the scheme's MPs, and there may be more MPs than marks (e.g. 7 MPs for 6 marks); follow-through only where the scheme allows it. No 9618 item is levels-based — the longest code questions are MP-marked too.
- A syntax detail the scheme ties to an MP loses that MP: missing ENDIF / ENDWHILE, a file name without quotes, a record field without dot notation, a reserved word as an identifier, a parameter overwritten by INPUT. Indentation is required only in Paper 4 Python.
- In a numbered space only the first answer counts; where N answers are asked, only the first N; synonyms count once (password and PIN).
- Exact terminology ("coding" is not "programming"); restating the question or a generic textbook answer earns nothing when the question has a scenario.
